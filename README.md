Guestbook
=========

A virtual guestbook - learn the complete GitHub pull-request workflow.

What is this?
-------------

I created this repo as a way to help people learn how to contribute to
open-source software on GitHub!  If you are new to GitHub or OSS then You can
use this repo as a starting point to make your first ever contribution or first
ever pull-request.  If you are already comfortable with that, or even consider
yourself a veteran, you are welcome just the same!

Put simply, every user can create their own text file in the
[`contributors`](/contributors) directory in this repo.

For example:

```
./contributors/your-github-username.txt
```

The file contains one line:

```text
Your-GitHub-Username was here 🎉
```

The filename itself must be lowercase but the casing in the file is up to you.
The final character may be any emoji (or unicode char) you'd like.
